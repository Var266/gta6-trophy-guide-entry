# GTA 6 trophy guide and tracker

[![rank](https://make.fun/badge/gta6-trophy-guide-01/Var266/gta6-trophy-guide-entry/rank.svg)](https://make.fun/c/gta6-trophy-guide-01)
[![reward](https://make.fun/badge/gta6-trophy-guide-01/Var266/gta6-trophy-guide-entry/reward.svg)](https://make.fun/c/gta6-trophy-guide-01)

An offline guide and tracker for the 55 PlayStation 5 trophies of Grand Theft Auto VI, built for the [make.fun bounty](https://make.fun/c/gta6-trophy-guide-01).

- Every trophy with its official name, description and grade, plus a guide in our own words citing Exophase and PSNProfiles.
- A checklist tracker: progress saved in localStorage, export to file and import back.
- Filters by kind (story, missable, collectibles, activities) and grade, a missable-only view, and a spoiler setting that hides unearned story trophies.
- A four-stage roadmap to the platinum, with missable trophies flagged.

Run it offline: serve `app/` with any static HTTP server and open `index.html`.
